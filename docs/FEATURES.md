# Features — Demo atual

## Jogável do início ao fim
1. Entrar na masmorra (sala inicial revelada)
2. Selecionar peça e mover por clique (casas azuis, MP limitados por D6)
3. Névoa revela salas ao entrar ("Área revelada")
4. Combate por turnos contra 2 Goblin Guerreiros
5. Goblin Arqueiro ataca à distância (alcance 5)
6. Baú interativo (destaque amarelo): loot de 2 Poções de Vida
7. Boss "Cavaleiro Ancestral" (120 PV, CA 18, Golpe Pesado/Lâmina Sombria/Escudo Sombrio)
8. Vitória ao limpar a dungeon; derrota se o cavaleiro cair

## Sistemas
- Turnos fixos: Cavaleiro → Goblins → Arqueiro → Boss
- Dados D4/D6/D8/D10/D12/D20 com popup animado
- Atacar / Habilidade / Defender / Inventário / Passar vez (botões + teclas 1–5)
- Inventário modal: equipar Anel de Defesa (+2 CA), remover itens, usar poção (consome ação)
- HUD: retrato, PV/Mana, atributos, ordem de turno, log, barra do boss, banners
- Câmera iso: WASD/setas pan, scroll zoom, shake em impactos

## Fora do escopo desta demo
Save/persistência, múltiplos heróis, XP/level up, áudio, arte final.
